## Gotchas
- **Gmail:** `GMAIL_PASSWORD` must be a Google **App Password** (16 lowercase letters). It was the account password until today and every send failed with `534 5.7.9`. It now works. A successful send writes **nothing** to the log; only failures do, so absence of an error is the only signal.
- **Never print `.env`.** Check shape, not value (length, character classes).
- `docs/api.json` is **CRLF**. Read as bytes, normalise, edit, write back as CRLF, or the whole file shows as changed.
- tenantcore only reads `.env` at startup. Restart it after editing, and **every restart ends console sessions** (tokens last 1h, so the user must sign in again).
- The mail route allows 10 sends/minute across all callers (`AUTH_RATE_PER_MINUTE`), shared with login.
- Reset **does not revoke existing sessions**: tokens are Ed25519 and verified offline.
- Windows shell: long Python heredocs have broken the shell repeatedly. Put scripts in a file and run it. A command that was moved to the background **keeps running its remaining steps** (including `git commit` and ledger writes), so do not chain those in one call.
